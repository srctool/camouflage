# Charts

Charts without a chart library, in their own package, `camouflage-charts` / `camouflage_charts` (ADR-40). Part of [Components — Overview](/components). They are not part of the skin contract: a chart follows the skin through tokens, the parts it reuses and a preset per skin name.

| Component | Milestone | What it proves |
|---|---|---|
| [Chart Frame](/components/charts/chart-frame) | M11 | the package, the data model, scales, axes, legend, tooltip, data table fallback and the style layers |
| [CamoSparkline](/components/charts/camo-sparkline) | M11 | the smallest chart: a trend with no axes, readable as text |
| [CamoLineChart](/components/charts/camo-line-chart) | M11 | line, area and stacked area |
| [CamoBarChart](/components/charts/camo-bar-chart) | M11 | vertical, horizontal, grouped and stacked bars |
| [CamoPieChart](/components/charts/camo-pie-chart) | M11 | pie and donut with a center label |
