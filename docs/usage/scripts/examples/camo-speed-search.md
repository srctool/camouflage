Type in a focused tree, data table or menu to filter it, with the matches highlighted and no search field. Matching is by prefix, substring or camel-hump (`fLog` finds `featureLogin`), ignoring case and accents. Up and Down move between matches in a tree, Backspace edits, and Esc clears the text before it closes anything; a live region tells screen readers "3 matches" or "No matches". There is no component of its own: you turn it on where you use a tree, a table or a menu.
