# CamoSplitPane

Panes side by side (`axis` `Horizontal`, first pane at the start) or stacked, with a draggable, keyboard and
screen reader accessible divider between each pair. The `state` is the app's: fractions of the container and
the collapsed panes, which it can `snapshot``CamoSplitState.snapshot` and restore. A divider moves space between
its two neighbours only, within their `minSize` and `maxSize`. Arrow keys resize (Shift for a larger step), Home
and End go to a limit, Enter collapses or restores a collapsible neighbour, a double-click resets the two
neighbours; a screen reader adjusts it like a slider. Right to left mirrors a horizontal split.

## Usage

<LangTabs>

<TabItem value="kotlin">

```kotlin
val state = remember { CamoSplitState(listOf(1f, 3f)) } // fractions, so a saved layout fits any window

CamoSplitPane(
    axis = Orientation.Horizontal,
    panes = listOf(
        CamoPane(minSize = 160.dp, collapsible = true) { Sidebar() },
        CamoPane(minSize = 240.dp) { Detail() },
    ),
    state = state,
)

// Save and restore the layout yourself
val saved = state.snapshot()
state.apply(saved)
```

</TabItem>

<TabItem value="dart">

```dart
final state = CamoSplitState([1, 3]); // fractions, so a saved layout fits any window

CamoSplitPane(
  axis: Axis.horizontal,
  state: state,
  panes: [
    CamoPane(minSize: 160, collapsible: true, child: const Sidebar()),
    CamoPane(minSize: 240, child: const Detail()),
  ],
);

// Save and restore the layout yourself
final saved = state.snapshot();
state.apply(saved);
```

</TabItem>

</LangTabs>

## API

<LangTabs>

<TabItem value="kotlin">

```kotlin
public fun CamoSplitPane(
    axis: Orientation,
    panes: List<CamoPane>,
    state: CamoSplitState,
    modifier: Modifier = Modifier,
)
```

| Name | Type | Default |
|---|---|---|
| `axis` | `Orientation` | `required` |
| `panes` | `List<CamoPane>` | `required` |
| `state` | `CamoSplitState` | `required` |
| `modifier` | `Modifier` | `Modifier` |

</TabItem>

<TabItem value="dart">

| Name | Type | Default | Description |
|---|---|---|---|
| `axis` | `Axis` | `required` | `horizontal`: panes side by side; `vertical`: stacked. |
| `panes` | `List<CamoPane>` | `required` | Two or more panes. |
| `state` | `CamoSplitState` | `required` | The layout, owned by the app. |

</TabItem>

</LangTabs>
