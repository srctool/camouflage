# CamoChip

A compact element whose callbacks decide its kind: a filter when `selected` is set (it toggles through
`onClick`), an input chip with a remove button when `onRemove` is set, an action chip with `onClick` only,
and a static tag with none (a status word in a `tone`: `Soft` + `Success` "Paid"). A focused input chip is
also removed with Backspace or Delete. Counts and dots are `CamoBadge`s, not chips.

<TabItem value="dart">

| Name | Type | Default | Description |
|---|---|---|---|
| `label` | `String` | `required` | The label, one line with an ellipsis (the full label in semantics). |
| `onPressed` | `VoidCallback?` |  | Activates an action chip, or toggles a filter chip. |
| `selected` | `bool?` |  | Non-null makes a filter chip. |
| `onDeleted` | `VoidCallback?` |  | Non-null adds a remove button (an input chip). |
| `leading` | `Widget?` |  | An icon or a small `CamoAvatar`. |
| `appearance` | `Appearance?` |  | `null` uses `CamoChipTheme.defaultAppearance`. |
| `tone` | `Tone` | `Tone.defaultTone` | A status tone, for tags. |
| `enabled` | `bool` | `true` | `false` disables the chip. |
| `focusNode` | `FocusNode?` |  | An optional focus node the app controls. |

</TabItem>
