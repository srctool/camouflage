# CamoRating

A rating of `value` out of `max`, read-only when `onChanged` is `null`. `label` names it ("Quality").

## API

<LangTabs>

<TabItem value="kotlin">

```kotlin
public fun CamoRating(
    value: Float,
    label: String,
    modifier: Modifier = Modifier,
    onValueChange: ((Float) -> Unit)? = null,
    max: Int = DEFAULT_MAX,
    step: RatingStep = RatingStep.Whole,
    size: RatingSize = RatingSize.Medium,
    enabled: Boolean = true,
)
```

| Name | Type | Default |
|---|---|---|
| `value` | `Float` | `required` |
| `label` | `String` | `required` |
| `modifier` | `Modifier` | `Modifier` |
| `onValueChange` | `((Float) -> Unit)?` | `null` |
| `max` | `Int` | `DEFAULT_MAX` |
| `step` | `RatingStep` | `RatingStep.Whole` |
| `size` | `RatingSize` | `RatingSize.Medium` |
| `enabled` | `Boolean` | `true` |

</TabItem>

<TabItem value="dart">

| Name | Type | Default | Description |
|---|---|---|---|
| `value` | `double` | `required` | The rating, 0 to `max`. |
| `label` | `String` | `required` | Names the rating. |
| `onChanged` | `ValueChanged<double>?` |  | Called with the new value; `null` makes it read-only. |
| `max` | `int` | `5` | How many icons. |
| `step` | `RatingStep` | `RatingStep.whole` | Whole or half steps. |
| `size` | `RatingSize` | `RatingSize.medium` | The icon size role. |
| `enabled` | `bool` | `true` | `false` disables it. |

</TabItem>

</LangTabs>
