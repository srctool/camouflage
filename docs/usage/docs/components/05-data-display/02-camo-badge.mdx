# CamoBadge

A count ("3") or, with no `count`, a dot, usually in a `CamoBadgedBox` on an icon or avatar. Above `max` it
shows "99+"; a count of 0 (or less) shows nothing. A badge is never focusable: its `contentDescription`
(default "3 new" / "New") joins its anchor's announcement. Count changes aren't announced; apps announce
the ones that matter.

## API

public fun CamoBadge(
    modifier: Modifier = Modifier,
    count: Int? = null,
    max: Int = 99,
    tone: Tone? = null,
    appearance: Appearance? = null,
    contentDescription: String? = null,
)

| `tone` | `Tone?` | `null` |
| `appearance` | `Appearance?` | `null` |

<TabItem value="dart">

| Name | Type | Default | Description |
|---|---|---|---|
| `count` | `int?` |  | The count; `null` makes a dot. |
| `max` | `int` | `99` | Above it the badge shows "$max+". |
| `tone` | `Tone?` |  | `null` uses `CamoBadgeTheme.defaultTone`. |
| `appearance` | `Appearance?` |  | `null` uses `CamoBadgeTheme.defaultAppearance`. |
| `semanticLabel` | `String?` |  | What the anchor says about the badge ("3 unread messages"). |
