# CamoDivider

A line between groups of content. Decorative: hidden from screen readers. A vertical divider needs a bounded
height (an `IntrinsicHeight` around a `Row`).

## API

<LangTabs>

<TabItem value="kotlin">

```kotlin
public fun CamoDivider(
    modifier: Modifier = Modifier,
    orientation: Orientation = Orientation.Horizontal,
    inset: DividerInset = DividerInset.None,
)
```

| Name | Type | Default |
|---|---|---|
| `modifier` | `Modifier` | `Modifier` |
| `orientation` | `Orientation` | `Orientation.Horizontal` |
| `inset` | `DividerInset` | `DividerInset.None` |

</TabItem>

<TabItem value="dart">

| Name | Type | Default | Description |
|---|---|---|---|
| `orientation` | `Axis` | `Axis.horizontal` | Horizontal or vertical. |
| `inset` | `DividerInset` | `DividerInset.none` | The inset. |

</TabItem>

</LangTabs>
