# Using Camouflage

Camouflage is a component library for Compose Multiplatform and Flutter where **what a component is** stays fixed and **how it looks** comes from a swappable **Skin** plus a **Theme**. A new app gets a new Theme, not new components.

These docs are for developers **using** Camouflage in an app: installing it, setting up a theme, and using the components.

:::info[Not released yet]

Camouflage has no published release yet. The guides here (installation, your first theme, the components in an app) are written with the first release, 0.1, when the API they show is real.

:::
